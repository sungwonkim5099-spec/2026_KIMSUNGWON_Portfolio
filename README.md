# 2026 KIM SUNGWON Portfolio

Snap-scroll portfolio home page based on the current Apple system responsive direction.

## Structure

- `index.html` - home page markup
- `styles.css` - responsive layout and visual system
- `script.js` - snap scroll and interaction behavior
- `assets/` - video, images, and SVG assets

## Deploy

This is a static site. On Vercel, use the default static project setup with no build command.
